RFMagMapper 使用說明書（白話版）

RFMagMapper 是一款幫你「看見家裡或辦公室看不見的無線訊號與電磁波」的測繪工具。只要拿著 Samsung Galaxy S24 Ultra 在室內走一圈，它就會畫出一張像氣象雲圖一樣的「熱區地圖」，告訴你哪裡 Wi-Fi 最強、哪裡有電線或變壓器產生的磁場。

1. 手機版安裝與行前準備（S24 Ultra）

  • 安裝 App：下載 RFMagMapper_S24Ultra.apk 到手機並點擊安裝（若跳出安全提醒請選擇允許）。
  • 開啟權限：第一次打開請點「立即授權所有權限」，讓 App 可以使用定位（讀取 Wi-Fi 與 GPS）、藍牙掃描與計步器。
  • 關閉手機掃描省電限制（重要！）：Android 手機為了省電，預設每 2 分鐘只會掃描 4 次 Wi-Fi，會讓地圖更新變慢。請依以下步驟關閉：
    ① 打開手機 設定 → 關於手機 → 軟體資訊，連續點擊 版本號碼 7 下開啟開發人員模式。
    ② 回到設定最下方進入 開發人員選項，找到並關閉「Wi-Fi 掃描節流」。
    （App 頂部也有引導卡片與按鈕，可一鍵跳轉設定頁；關閉後走路時地圖就會每秒即時更新！）

2. 五大偵測功能在看什麼？

  • Wi-Fi 訊號強弱（支援 Wi-Fi 7）：把周圍所有 Wi-Fi（2.4G / 5G / 6G）的總能量加起來，並列出訊號最強的前 3 台路由器，方便你找訊號死角。
  • 藍牙裝置密度：看看周圍有多少藍牙設備（耳機、手錶、智慧家電）正在發射訊號。
  • 電器與牆內電線磁場（60Hz 低頻磁場）：家裡的微波爐、配電箱、變壓器或牆壁裡的電線，通電時會產生看不見的交流磁場。這個功能能幫你找出這些「電磁熱區」，避開長期坐在高磁場旁邊。
  • 室內走路定位與樓層判斷：室內收不到 GPS 沒關係，App 會用手機的計步器與陀螺儀記錄你往哪裡走了幾步；上下樓時氣壓計還會自動幫你切換樓層。
  • 窗邊／戶外 GPS 標記：靠近窗邊時自動記下經緯度，幫整張室內地圖做一個地理標記。

3. 瀏覽器版怎麼用？

  • 互動模擬：直接在左邊地圖上用滑鼠點擊，或按鍵盤 W / A / S / D（方向鍵）移動，也可以按「▶ 自動巡檢模擬」體驗熱區地圖的繪製過程。
  • 匯入手機數據回放：在手機端按「匯出 JSON」後，透過右上角「匯入 Android JSON」上傳檔案，就能在電腦大螢幕上檢視四種圖層並匯出 PNG 圖片。
